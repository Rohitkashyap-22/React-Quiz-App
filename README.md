# Quiz App

A simple and interactive Quiz App built using **React.js**. Users can answer multiple-choice questions, navigate through the quiz, track their score, and restart the quiz.

## Features

- Multiple-choice questions.
- Select an option for each question.
- Next Question button remains disabled until an option is selected.
- Automatic score calculation based on correct answers.
- Displays the final score after completing the quiz.
- Reset Quiz functionality to start again.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Concepts Practiced

- React Functional Components
- useState Hook for state management
- Props for passing data between components
- Conditional Rendering
- Event Handling

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Rohitkashyap-22/React-Quiz-App
   ```

2. Navigate to the project directory:

   ```bash
   cd React-Quiz-App
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
